# swiyu Bug Bounty

The swiyu Bug Bounty Program has been running since July 2025. It operates as part of the federal government’s Bug Bounty Program, which is overseen by the Federal Office for Cyber Security (BACS) and run in collaboration with SignalFisher (former Bug Bounty Switzerland AG).

Through such a program, ethical hackers are rewarded for identifying vulnerabilities. Until April 2026, this program has been run in private mode. This meant that only selected hackers could participate by invitation.

Since April 2026, the program is in [public mode](https://signalfisher.com/de/projects/swiyu). This means that all hackers can register and be rewarded for vulnerabilities they find.
